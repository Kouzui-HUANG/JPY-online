[JP¥ ONLINE](https://jpyonline.com/) 是 2026 年 4 月創刊的獨立日系商業媒體。我們把日本的一手公開資料，也就是決算短信、官方統計、法令原文，拆成台灣經營者與投資人能直接拿去做決定的判斷材料：日本公司怎麼賺錢、日銀和日圓在想什麼、在日本買房要繳哪些稅、哪裡值得去、什麼東西值得懂。

這個 repo 是 JP¥ ONLINE 的官方營運日誌，記錄我們在做什麼、做到了哪裡、接下來要做什麼。網站本身的程式碼不在這裡。

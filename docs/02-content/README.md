## 內容形式

站上的文章大多屬於以下八種形式，每種形式都有固定的結構。

### 1. 企業三部曲

| 篇 | 回答的問題 | 範例：東京威力科創 |

| 一 | 這家公司是什麼、怎麼賺錢 | [東京威力科創是做什麼的？](https://jpyonline.com/post/2606241500_tokyo-electron-chip-equipment-hidden-champion/) |
| 二 | 為什麼別人學不來（護城河或關鍵轉折） | [東京威力科創護城河解析](https://jpyonline.com/post/2606241505_tokyo-electron-asml-moat-why-irreplaceable/) |

### 5. 總經剖析

定期解讀日銀、日圓、物價、薪資與 GDP。2026 年 4 月創刊號起至今 12 期，6 月起多為每月月初、月中各一期。詳見 [總經趨勢](macro.md)。

### 6. 深度旅遊

第一人稱散步開場，加上票價、交通、開放時間等實用資訊，文末回答讀者最常問的問題。2026-10-13 起近乎每日一篇。詳見 [旅宿動態](hospitality.md)。

### 7. 美食雙篇

同一種食材或料理寫兩篇：科普篇講工法與文化，名店朝聖篇整理老舖地圖，兩篇互連。例如鰻魚的〈[關東關西差在哪](https://jpyonline.com/post/2607131700_unagi-kanto-kansai/)〉與〈[六家鰻名店的朝聖地圖](https://jpyonline.com/post/2607131730_unagi-famous-restaurants/)〉。

### 8. 四個冷知識

用四個冷知識讀懂一支酒與它背後的酒藏，例如〈[而今清酒是什麼？](https://jpyonline.com/post/2606151714_jikon-sake/)〉。詳見 [品味生活](lifestyle.md)。

## 分類之間怎麼串

| 機制 | 做法 |
|---|---|
| 主題標籤 | 178 個標籤跨分類把同一主題串成專題頁，例如「日圓貶值」「半導體產業趨勢」「J-REIT不動產信託」 |
| 站內語境連結 | 文章內文直接連到相關深度文，只在真正相關時才連 |
| 排行樞紐 | 一篇總表連出數十篇個別公司文 |
| 延伸閱讀 | 文章頁底部依同分類、同主題推薦 |

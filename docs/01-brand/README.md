## 一句話

**JP¥ ONLINE，給台灣經營・投資者看的日本商業情報誌**。

品牌標語是「AI 時代的商業洞察」。在資訊幾乎免費的時代，我們只回答一個問題：讀完之後，你的下一個決定有沒有變得更好。我們對「資訊量」沒興趣，對「判斷增量」才有。

## 名稱由來

| 字 | 意思 |
|---|---|
| JP | 日本 |
| ¥ | 錢與資本，以日幣符號取代英文字母 Y |
| ONLINE | AI 時代的閱讀載體 |

我們以日本市場為圓心，向外連動到台灣資本、亞太資金與全球 AI 趨勢。用 ¥ 取代 Y，是要讓讀者第一眼就明白：這不是觀光紀錄，是商業現場。

## 我們服務誰

1. 對日本市場有實際曝險、或計畫進入日本的台灣經營者與投資人
2. 負責跨境業務、需要快速理解日本法規與市況的公司決策層
3. 把日本當成生活與投資延伸場域的高資產專業人士
4. 不想讀第三手新聞、希望直接拿到一手判斷的商業內容讀者

## 我們相信什麼

- 日本是台灣最值得理解、也最常被誤讀的市場之一。從日銀政策、日圓匯率、宅建業法到建設業的 2024 年問題，台灣讀者長期透過第三手翻譯新聞理解日本，損失了大量判斷時間。
- 一手資料比二手轉述值錢。能拿到原始檔案，就不轉述新聞稿。
- 文章的價值不在流量，在你之後做的決定。判斷可能出錯，但每篇文章都要有立場。

## 速度

- 首頁與六大分類頁的列表先顯示 5 篇，捲到底再載入下一批。首頁頁面體積從約 852KB 降到約 64KB（2026-08-17）。
- 封面圖依螢幕大小載入合適的尺寸（2026-07-02）。

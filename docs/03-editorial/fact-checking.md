# 查核原則

[← 編輯室](README.md) ・ [回到首頁](../../README.md)

這份清單整理自我們在編輯台上實際攔下過的錯誤類型。每篇文章上線前都要逐項跑過。

## 三條總原則

1. **一手來源優先**。核心主張一律回到官方 PDF、法令原文、統計原表。二手報導、中文編譯稿與財經彙整網站只當線索。
2. **查無一手出處就不寫**。寧可少一個漂亮的形容詞，也不留一個查不到的說法。例如「世界第一」若找不到官方出處，整句刪除。
3. **錯誤寫回底稿**。查核時發現的錯誤記錄在研究底稿開頭，避免下一篇重蹈覆轍。

## 數字

| 檢查項 | 怎麼做 |
|---|---|
| 財務數字 | 營收、利益逐欄對回決算短信；年增率自己算。彙整網站上的「前期比」可能是財測的年增率，不是實績 |
| 財測版本 | 確認是期初財測還是季報後的修正版 |
| 日文百分比 | 「前年度比 138.2%」是指數，代表成長 38.2%。若百分比與同一張表的增額只差一個小數點位置，多半是誤讀 |
| 「創新高」「首次」 | 先查歷史數據能回溯到哪一年；資料只到某一年，就只能說「該年以來」 |
| 匯率換算 | 台幣換算註明匯率與日期。用日圓、台幣兩組數字相除，檢查隱含匯率是否過期 |
| 「連續 N 個月」 | 回到原始新聞稿或統計表確認月數 |
| 統計基準 | 例如日本 CPI 自 2026 年 8 月公布的數據起改採 2025 年基準，新舊文章對照前先確認基準年 |

## 主體與時序

| 檢查項 | 怎麼做 |
|---|---|
| 同集團、同名法人 | 分清楚是哪一家。例如台灣積水化學屬積水化學系，與積水房屋無關 |
| 會計年度 | 日本多數公司以 4 月為年度起點，事件日期要對得上報告所屬的年度 |
| 舊聞翻新 | 確認事件發生的年份。我們攔下過把多年前的舊事件寫成當年新聞的案例 |
| 官方否定句 | 官方文件寫「不」的地方，不能被改寫成肯定句 |
| 因果方向 | 確認是 A 導致 B，還是 B 導致 A |

## 法規

| 檢查項 | 怎麼做 |
|---|---|
| 條號 | 以現行施行版的法令原文為準，條號會隨修法位移 |
| 地方條例 | 單獨查核原文，不沿用二手引述 |
| 條件句 | 逐句核對方向：誰觸發義務、誰負義務 |
| 罰則 | 日本法常見「義務條文本身沒有罰則，罰則掛在違反行政命令上」，不能寫成一違反就罰 |
| 具名人物 | 沒有一手出處的具名官員、發言與答辯紀錄一律不寫 |
| 簡化規定 | 別漏掉條文裡讓事情變簡單的規定，例如免除、當然兼任、刑事罰與行政罰的差別 |

## 台灣關聯

- 台灣關聯段落一律先視為未查核，逐條用官方公開資料核對：公司登記（統一編號、股東、公司狀態）、藥品許可證等
- 查不到就寫查不到，不補推測
- 一張許可證可能對應多家製造廠，計數時依證號去重

## 跨文章一致性

同一個事實在不同文章裡的說法要一致。發現新舊文章互相矛盾時，回頭修正舊文。

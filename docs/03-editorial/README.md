## 我們交付什麼

判斷增量。不是「日本發生了什麼」，而是「這件事對你的錢、你的公司、你的下一步代表什麼」。

## 三件堅持

1. **一手公開資料優先**。日銀、總務省、國土交通省、上市公司的決算短信與 IR 資料、東證的適時揭露、法令原文、主管機關公告：能拿到原始檔案，就不轉述新聞稿。
2. **結論不藏尾**。每篇文章在前 200 字內給出主結論，後段才是推論過程。趕時間的讀者讀完開頭就能下決定。
3. **不寫安全的廢話**。「未來仍有不確定性、需密切觀察」之類的句子，不會出現在我們的版面上。判斷可能錯，但要有立場。

## 文章骨架

每篇文章都依「場景、推論、建議」三段組織：先讓讀者看見一個具體場景，再拆開背後的機制，最後給出可以採取的行動。

## 選題原則

1. **寫判斷，不寫定義**。優先寫「為什麼」「怎麼選」「A 和 B 是什麼關係」「排名前十」「算給你看」。要寫「XX 是什麼」，標題必須帶一個官方網站或百科給不出的具體數字或反常識事實。
2. **台灣關聯是獨家角度**。供應鏈、股權、在台布局，以及只有台灣讀者才會問的問題。
3. **揭露結構，不重述常識**。最有價值的文章，往往揭露一個對台灣讀者不利的利益結構，例如〈[日本房仲兩手仲介是什麼？](https://jpyonline.com/post/2607311205_japan-real-estate-brokerage-double-agent/)〉。
4. **商業習慣不寫禮儀，寫損益**。名片、鞠躬、敬語、送禮一律不寫。每一段都要能回答：這條弄錯，你會多付多少、交割延後幾天、在哪裡失去否決權。
5. **旅遊選題看問題，不看名氣**。比起人人都寫的熱門景點，優先寫台灣旅人真正會問的問題、跟台灣有連結的地方，以及當年度的新設施與活動。
6. **開工前先查站內**。站上已經寫過的切角不再當主軸，新文章要補上站上還沒有的那一塊。

# 一篇文章的製作流程

[← 編輯室](README.md) ・ [回到首頁](../../README.md)

每篇文章從選題到上線，都走同一條九步流程。

```
選題 → 研究底稿 → 專欄改寫 → 事實查核 → 讀者 FAQ → 封面 → 上稿 → 站內織網 → 上線驗證
```

## 1. 選題

- 盤點站上既有文章與主題標籤，避免重複切角
- 確認讀者真的會問這個問題
- 決定這篇要讓讀者多會判斷哪一件事

## 2. 研究底稿

- 蒐集一手資料：決算短信、有價證券報告書、決算說明資料、中期經營計畫、官方統計與公告、法令原文、官方網站
- 整理成一份完整的研究底稿，重要數字附上出處
- 涉及台灣的段落，另以台灣官方公開資料核對，例如公司登記與許可證資料

## 3. 專欄改寫

- 依分類版式，把研究底稿改寫成給讀者的版本：台灣讀者視角，依「場景、推論、建議」組織
- 前 200 字給出主結論
- 擬兩個標題：頁面上的文學鉤子標題，以及貼近讀者搜尋用語的問句標題
- 摘要約 150 字

## 4. 事實查核

- 核心主張逐條回查一手來源，查不到出處的就刪
- 財務數字整表對帳，年增率自己算
- 詳見 [查核原則](fact-checking.md)

## 5. 讀者 FAQ

- 抽出全文最難懂的三個概念，寫成讀者會問的問答
- 每題答案 4–7 句

## 6. 封面

- 從文章抽出 1–3 個抽象概念，畫成極簡幾何封面
- 規範見 [視覺識別](../01-brand/visual-identity.md)

## 7. 上稿

- 設定分類、主題標籤、兩個標題、摘要與封面替代文字
- 連載三部曲先為三篇預排上架時間，互相寫好連結後同日上架
- 重大專題上線時，輪替首頁頭版頭條

## 8. 站內織網

- 在既有文字裡加入指向相關深度文的語境連結；主題只是泛泛相關就不連，寧缺勿濫
- 更新站內搜尋索引
- 新文章需要改動舊文章時，新舊兩篇一起上線

## 9. 上線驗證

- 網站建置零錯誤，並檢查粗體、表格與 FAQ 是否正確顯示
- 上線後逐一打開新網址，確認讀者看得到
